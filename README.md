# EduCenter — Student Management Dashboard

هذه نسخة Frontend تجريبية قابلة للرفع على GitHub Pages.

## التشغيل
افتح `index.html` مباشرة أو ارفع المشروع على GitHub Pages.

## مهم
هذه النسخة **واجهة Prototype** ولا تحتوي على Backend أو قاعدة بيانات حقيقية.
قبل الاستخدام الفعلي لبيانات الطلاب يجب ربطها بـ Supabase/Firebase أو Backend آمن.

المزايا الموجودة في الواجهة:
- Dashboard المدير
- الطلاب والمعلمين والمجموعات
- الحضور وحصة الحل
- الامتحانات والدرجات
- النقاط والتقييم
- المحادثات والإشعارات
- إعدادات الحساب
- رفع خط وتطبيقه تجريبيًا
- استخراج بيان الطالب للطباعة/PDF عبر نافذة الطباعة

## الحسابات
لا توجد Authentication حقيقية في هذه النسخة.
