# نظام إدارة سنتر مستر يحيى سرور

هذه نسخة واجهة أولية قابلة للتشغيل مباشرة، ومجهزة لتوصيل Supabase.

## التشغيل
يمكن فتح `index.html` مباشرة في المتصفح.

## ملاحظة
النسخة الحالية تحتوي على بيانات تجريبية داخل JavaScript لتوضيح شكل النظام ومنطق:
- تسجيل الدخول التجريبي بآخر 6 أرقام من الهاتف.
- إظهار حصة الحل للصف الثالث فقط.
- عرض مجموعات اليوم حسب اليوم الحالي.
- استعادة يوم سابق.
- تسجيل حضور تجريبي.

قبل الاستخدام الفعلي يجب ربط المشروع بـ Supabase وإضافة Authentication وRLS والجداول الفعلية.
